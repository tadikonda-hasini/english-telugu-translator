# English ↔ Telugu Translator

An AI-powered web application for translating text between English and Telugu using the NLLB-200 neural machine translation model.

- Python
- Flask
- PyTorch
- Hugging Face Transformers
- NLLB-200
- HTML
- CSS
- JavaScript
